# 内页背景清理

日期：2026-09-23。

用户截图右侧的矩形、投影和竖线来自共用 `Backdrop.astro` 的内页装饰层。已删除 `page` 与 `minimal` 变体的全部装饰子节点，保留固定主题底色；首页首屏几何构图和归档虚线时间轴仍保留。规则同步到 AGENTS.md 与 UI/UX 规范。

## 验证

- 清理后重跑完整 `pnpm verify` 全部通过：类型检查无错误（58 个文件，0 错误 0 警告），22 项单元测试、完整构建与 57 个 HTML 产物检查、48 项 Chromium 浏览器测试全部通过。
- 背景专项测试「内页与简化变体只保留底色，不残留装饰面板和线条」通过：检查文章、归档、关于（中英文）、类型、标签、搜索、404 的背景没有装饰子元素，且不接收指针事件；并检查分页使用内页背景。
- 此前一轮的全量失败没有在本轮复现。当时的失败为预览端口 4329 的 `ERR_CONNECTION_REFUSED`、主题单选控件定位超时，以及录制测试 trace 文件缺失；这些现象与本次背景改动无关，重跑时同一批测试全部通过，因此未修改主题实现与测试服务器机制。
- 依赖提示：本次验证使用仓库锁定的 pnpm 10.22.0。环境里 PATH 上的 pnpm 11 会因锁文件缺少 `packageManager` 依赖条目而直接拒绝运行脚本，命令与说明见 [开发规范](../../development.md)。
