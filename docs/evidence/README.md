# 视觉证据

本目录保存 `pnpm test:e2e` 中「视觉证据」用例产出的真实浏览器截图，用于人工复核界面在改动后仍然完整。截图来自构建产物（`astro preview`，4329 端口），不来自包含草稿的开发服务器。

## 目录

| 目录 | 内容 |
| --- | --- |
| `desktop/` | 1440×900：中文首页、英文首页、文章页、归档页、关于页、英文搜索面板 |
| `tablet/` | 768×1024：中文首页、英文首页、文章页、归档页 |
| `mobile/` | 390×844：中文首页、英文首页、文章页、归档页、导航面板 |
| `dark/` | 深色主题下的中文首页与文章页 |
| `screenshot-stats.json` | 每张截图的尺寸、平均亮度与通道方差 |

## 如何判读

- 截图是整页（full page）截图，因此高度随内容变化。
- `screenshot-stats.json` 中的 `spread`（通道标准差）低于 5 说明画面接近纯色，通常意味着样式没有加载；`luminance` 在深色主题下应显著低于浅色主题（当前实测约 41–67 与 234–246）。
- 像素统计只能发现「空白或样式丢失」这类问题，界面观感与设计意图仍需人工复核截图本身。

## 重新生成

```powershell
pnpm build
pnpm test:e2e -- --grep "视觉证据"
```

覆盖首页、文章、归档、关于、搜索面板、移动端导航与深色主题，任意一项失败都会保留 `test-results/` 中的失败上下文。
