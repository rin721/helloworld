# 重构残留清理记录

2026-09-23，针对用户指出的卡片顶部细线，检查了全部页面模板、公共组件、全局样式、伪元素、边框与浏览器渲染结果。

## 定位与处理

| 位置 | 原因 | 修复 |
| --- | --- | --- |
| 关于页三个辅助卡片 | 模板仍插入绝对定位的 `.hairline` | 删除装饰元素 |
| 文章标题、元信息、桌面／移动目录、结束卡片 | 同类短线散落于多个模板区域 | 删除元素，目录当前项改用底色和文字强调 |
| 内容列表结束语 | 沿用两侧横线装饰 | 删除横线，通过留白收束列表 |
| 首页介绍、公共模态与浮层 | 面板保留边框工具类 | 移除描边，保留表面、渐变和空间阴影 |
| Markdown 代码框 | 全边框与学习笔记左侧强调线叠加 | 改为阴影区分；补回 Shiki 双主题变量消费规则，恢复语法配色 |
| 标签筛选 | 回退入口隐藏条件写反，且组件层 display 被 Tailwind 工具层覆盖 | 在 utilities 层按脚本可用性隐藏，正常模式只显示交互入口，无脚本显示静态链接 |
| 搜索清空与高亮 | 系统清空按钮与组件按钮并存，mark 使用默认黄底 | 隐藏系统清空按钮，命中词使用语义主题色 |
| 搜索结果重复 | load 与 astro:page-load 对同一表单重复接线 | 按表单节点进行 WeakSet 幂等初始化，避免重复插入结果 |

公共 Panel、内容卡片、类型／标签索引、归档与页脚没有发现同类顶部装饰元素。独立背景和首页旁注短线属于参考图构图；控件边界、输入焦点、目录状态、表格网格、引用标记和作者写入的 Markdown 分隔线保留。

删除了 `.hairline` 样式定义，而非用透明度或遮挡掩盖。生产产物检查同时拒绝该类的 HTML 残留与旧 CSS 规则。新增浏览器场景验证有／无脚本入口、重复初始化后的结果数量及主题高亮。
