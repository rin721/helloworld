# UI/UX 规范

这份文档是产品视觉与交互的权威来源；组件接口与交互机制见 [UI 组件与交互机制](components.md)。

## 视觉基准与设计变量

仓库根目录的 `ui.png` 是用户提供的设计基准：浅蓝灰、留白、几何光影、衬线标题、半透明面板与直角矩形。首页为真实 DOM 与 CSS 构图，示例插画为本地资产。

设计变量集中在 `src/styles/global.css`：语义变量（`--c-*`、`--elev-*`、`--backdrop-*`）在浅色与深色下重新配置同一组名称，再通过 `@theme inline` 暴露成 Tailwind 的颜色、阴影与缓动，组件用 `bg-surface`、`text-ink`、`border-line`、`shadow-panel` 等工具类消费，不直接写色值。排版使用本机可用的中文与英文衬线／无衬线字体，不依赖远程字体请求。

## 配色（主题色）

颜色有两根正交的轴：**明暗外观**（`data-theme`：system／light／dark）与**配色**（`data-palette`）。配色默认 `slate`（蓝灰），另有 `jade`（青绿）、`violet`（紫罗兰）、`clay`（暖橙）、`graphite`（石墨）。

- 每份配色覆盖同一组变量：强调色三件套（`--c-accent`、`--c-accent-soft`、`--c-on-accent`）、浅色面与底色（`--c-canvas`、`--c-soft`、`--c-line`、`--c-line-strong`、`--c-glass`、`--c-glass-strong`）、背景几何（`--backdrop-*` 十项）以及背景水印文字 `--c-on-backdrop`。
- **明度阶梯共用**：浅色底约 L96%、表面 L100%、深色底约 L12%、表面 L17%，配色只改色相与彩度，因此阅读舒适度与对比度可控。正文三色（`--c-ink`、`--c-muted`、`--c-faint`）与投影 `--elev-*` 不随配色变化。
- 默认 `slate` 的取值与引入配色轴之前逐字节一致，不产生视觉回归（有断言保护）。
- 代码高亮（Shiki 的 github-light／github-dark）不随配色变化：语法配色不应被主题色带动。
- `--c-swatch-*` 是色板预览用的固定身份色，只在设置浮层里使用，组件不写死色值。

| 配色 | 浅色强调色 | 深色强调色 |
| --- | --- | --- |
| 蓝灰 `slate` | `#476282` | `#b2c9e1` |
| 青绿 `jade` | `#2f6d63` | `#a9d6cd` |
| 紫罗兰 `violet` | `#5b4a86` | `#c9bee6` |
| 暖橙 `clay` | `#93502f` | `#e0b291` |
| 石墨 `graphite` | `#4b5359` | `#c2cad1` |

对比度门槛（浏览器测试对 5 份配色 × 2 种明暗共 10 组逐项断言）：正文 `--c-ink` 对底色 ≥ 7:1、次级文字 `--c-muted` 对底色 ≥ 4.5:1、`--c-faint` 对表面 ≥ 3:1、`--c-on-accent` 对强调色 ≥ 4.5:1、强调色对浅色面与底色均 ≥ 3:1。新增配色必须同时通过这组断言。

配色通过 `localStorage` 的 `palette` 键保存，并在首次绘制前与软导航后（`astro:after-swap`）写回 `<html data-palette>`；未知取值回落 `slate` 并清理存储键。手动切换时会临时加上 340ms 的颜色过渡类，减少动效模式下不播放。

## 卡片语言

- 主体一律是直角矩形，靠背景色面、间距和柔和阴影分组，**不使用分隔线**：内容条目之间、筛选栏上下、归档行与普通卡片都没有描边。
- 内容容器内不放置顶部短线、标题下划线或结束语两侧横线；旧 `.hairline` 元素和样式已移除，产物检查禁止恢复。目录当前位置以色面强调，代码框、介绍面板和浮层不依赖描边。
- 独立背景短线与首页旁注中的短线属于参考图构图；面板高光是渐变色面，不是边框。保留控件边界、输入焦点、表格网格、Markdown 作者写入的分隔线和引用标记，因为它们承担操作或内容语义。
- 每个内容条目是独立表面（`Panel variant="surface" shadow-card`）并带 `lift` 悬停抬升；列表用 `gap` 分隔而不是边框。
- 类型／标签卡片带几何切片（`.geo-slice`）、标题、数量与方向按钮；类型三列、标签自适应网格，手机单列，长标签允许换行。

## 页面与模板

- 首页第一页：导航 → 介绍面板 → 精选卡片 → 类型与标签筛选 → 单列卡片流 → 分页 → 页脚。
- 类型与标签索引是有几何切片的面板卡片；归档按月份组织成面板；搜索的输入、结果、加载、无结果与错误使用同一套组件语言。
- 归档月份面板内增加纵向虚线时间轴：日期在左、文章在右，月份用空心圆起始、文章用小圆点标记，轴线终止于末条节点。手机日期简写为 MM-DD、标题允许多行；主题色与键盘焦点沿用公共变量。这是用户指定的时间顺序表达，不属于旧的卡片装饰残线。
- 详情、关于与 404 延续几何页头、阅读面板与辅助卡片；正文保持约 740px 行宽。
- 文字卡片通过标题、摘要与留白组织层级；图文增加封面；手机上图片移到文字上方。
- 图片分享允许没有摘要，预览使用完整图片比例，详情按顺序展示图片。
- 详情共用标题、日期、类型、标签和相邻文章导航；日记把日期放大，学习笔记强化目录、代码与表格，画廊让正文满宽。
- 图片放大支持 Enter／空格打开、左右方向键切图、Escape 关闭并恢复焦点。
- 全站保留可直接访问的静态链接；浏览器脚本不负责生成文章主体。

## 背景层次

首页首屏背景由大小不同的矩形面板错位、叠放、局部遮挡构成，分四个层级：底色 → 远层几何 → 中层卡片 → 前景内容。背景不再使用立柱式色块、贯穿首屏的斜向光束或地面分界。

- 底色：接近白色的冷蓝灰，中央明亮、边缘轻微加深，没有强烈渐变。
- 远层几何：右上、左下各一个大矩形，部分超出容器裁切，低对比度，用来建立画面尺度。
- 中层卡片：右侧三张不同尺寸的矩形面板，横向纵向交错并按 DOM 顺序形成可辨认的遮挡；浅灰蓝、雾白、中灰蓝各一，直角、柔和投影，只在局部使用细微边缘高光，不给每张面板描边。
- 前景内容：介绍面板与精选文章保持最高层级，背景卡片从其边缘局部露出；介绍面板背后的区域保持平静，文字行盒不与中层面板重叠。精选文章后方有一张向右上错开的底板，只露出部分边缘。介绍面板自带一层很淡的斜向光面（`panel-highlight`）作为几何光影，不铺成横跨首屏的光束。
- 装饰面板不含文字、按钮或文章缩略图，不制造可点击的错觉。

实现分工：面板的位置、尺寸、透明度与响应式由 `src/components/Backdrop.astro` 和 `Hero.astro` 中的 Tailwind 工具类给出；底色、各层颜色、投影与边缘高光使用 `--backdrop-*` 共享变量；面板表面、边缘高光与入场动效是 `global.css` 中的 `.backdrop*` 规则。背景容器与底板都带 `aria-hidden`，并设置 `pointer-events: none`，处在其独立层叠上下文的最底层。

| 变体 | 使用位置 | 内容 |
| --- | --- | --- |
| `home` | 首页第一页的首屏 | 完整的远层、中层、底板与少量细线 |
| `page` | 归档、类型、标签、关于、详情与分页列表 | 仅固定主题底色，无背景装饰面板、阴影和线条 |
| `minimal` | 搜索与 404 | 同样仅保留主题底色，保留现有变体接口 |

## 空间动效

| 场景 | 参数 |
| --- | --- |
| 背景分层视差 | 指针与滚动位移相加后不超过 16px（远层 8px、中层 16px）；触屏、减少动效、离开视口或切到后台时暂停并归位；正文区域不参与位移 |
| 卡片入场 | 480ms 淡入与 16px 位移，同组错峰 60ms、累计不超过 240ms；进入视口只播放一次 |
| 卡片悬停 | 220ms、最多 6px 抬升，配合表面变化与箭头位移；键盘焦点给出同样反馈 |
| 浮层与模态层 | 打开 240ms 淡入、短位移与轻微缩放，关闭 180ms |

不使用持续漂浮、自动旋转或循环缩放。手机只保留两块局部裁切的背景面板与精选底板，并关闭指针视差；粗指针、视口小于 761px 或系统要求减少动效时同样不启用。深色模式逐层重新配置底色、面板明度与投影，不对整块背景统一降低亮度；减少动效时关闭视差、错峰与空间位移，直接呈现完整静态构图。

## 交互与控件

- 明暗外观与配色都在页头的「外观与配色」设置浮层里：外观是定制分段选择（`SegmentedControl`），配色是五色色板（`PaletteSwatches`），都支持键盘选择与持久化；外观还跟随系统变化。浮层由色彩板图标按钮触发（颜料点填当前强调色，图标即当前配色的提示），支持外部点击、Escape 关闭与焦点返回，并且把方向键让给内部的两组 radiogroup。
- 标签筛选是按钮触发的链接浮层，支持外部点击与 Escape 关闭；移动目录是自定义展开区域，桌面保持侧栏目录。
- 译文提示、图片查看与移动导航共用自建模态控制器：同一时间只打开一个模态层，背景不可操作、滚动锁定、焦点循环并在关闭后回到触发元素。
- 详情有译文时直接切换；无译文时弹出说明，读者可以关闭继续阅读或进入目标语言首页。
- 列表切换语言时回到对应语言第一页；标签名称没有翻译映射时进入目标语言的标签索引，避免生成不存在的链接。
- 搜索支持输入、加载、结果、无结果、失败和重试；结果摘要高亮经过白名单处理。
- 禁用 JavaScript 时保留导航、分类与标签链接、分页、正文和展开的目录；脚本专属控件不显示为不可操作按钮。

## 软导航与主题

站点使用 Astro 的客户端路由（`<ClientRouter />`）做软导航：点击站内 HTML 链接时客户端取回新页面、只替换文档内容，不再整页重载。地址栏仍然会变成新地址（`pushState`），这是深链、后退／前进与刷新恢复所必需的；变化的只是不再有白屏与整页重建。

- 路由过渡是非对称的：出场 200ms 收起，入场 340ms 淡入并带 8px 位移，两段叠在一起衔接，避免切换显得生硬。减少动效模式下关闭。
- 手动切换主题时给根元素加一个 340ms 的临时过渡类，让底色、文字与阴影平滑过渡；跟随系统变化与页面加载都不播放这段过渡，也不会留下常驻 transition。
- 软导航时背景几何不重播入场（`html[data-navigation='soft']`），保持空间连续；卡片仍在进入视口时错峰入场一次。
- 非 HTML 目标（`/zh/rss.xml` 等）带 `data-astro-reload`，交回浏览器整页处理。
- 预取只在悬停时发生（`prefetchAll: true` + `defaultStrategy: 'hover'`）。
- 主题设置位于页头，每页可见：紧凑分段选择只显示图标，名称由 `sr-only` 与 `title` 提供。
- 路由会重置 `<html>` 的属性，因此在 `astro:after-swap`（绘制前）重新写回 `data-theme`、`data-resolved-theme`、`data-palette` 与 `js` 类；明暗与配色在软导航前后都保持，不会闪回默认值。
- 选中态由控制器在 `astro:page-load` 同步到页面上所有 `[data-segmented]` 分组；跟随系统时系统变化仍会立即生效。
- 打开模态层时导航不会把 `inert` 与滚动锁带到新页面：`astro:before-swap` 会先复位模态与浮层。

## 页头的滚动行为

页头不常驻固定顶部，而是随滚动切换三种状态（`data-header-state`），桌面与手机一致：

| 状态 | 触发 | 外观 |
| --- | --- | --- |
| `top` | 距顶 24px 以内 | 玻璃底、无阴影，跟随页面滚动到该位置 |
| `pinned` | 距顶超过 24px，且向上滚动 ≥ 6px 或页头内有键盘焦点 | 更实的玻璃底 + 柔和阴影，贴顶滑出 |
| `hidden` | 距顶超过 96px 且向下滚动 ≥ 6px，且页头内无焦点、滚动未锁定 | 整体上移滑出视口，把空间让给内容 |

- 方向阈值 6px 用来吸收移动端地址栏收缩与细碎滚动；顶部 24px 静区内始终保持 `top`。
- 页头隐藏时**不**设置 `inert`，也不使用 `visibility: hidden`：那会让导航与主题控件在滚动状态下对键盘和读屏不可达。保留可聚焦，并在 `focusin`（以及浏览器把焦点滚入视野时）立即切回 `pinned`。
- 模态层锁定滚动期间不做状态变更；软导航后由 `astro:page-load` 重新测量与判定，`astro:before-swap` 复位为 `top`。
- 动效是**非对称**的，避免生硬：隐藏 260ms、`cubic-bezier(.45,0,.75,.25)` 渐渐加速离开；滑出 420ms、`cubic-bezier(.22,1.28,.36,1)` 减速并在贴顶时轻微回弹后稳定。过渡作用在 `translate`／`scale` 上，方向切换时可被中断并直接从当前位置继续。
- 位移到 −102% 并伴随 0.985 的纵向轻微收拢，避免边缘阴影在滑出过程中露出。
- 强调外观由单独一层用透明度淡入（360ms，延迟 40ms），不改动底色本身，因此切换过程没有颜色突跳。
- 首次加载时页头内容有一次 460ms 的淡入与 10px 下移归位；软导航不再重播，避免每次翻页都停顿一下。
- 减少动效模式下由全局规则关闭过渡与动画，状态瞬时切换。
- 隐藏与显现不改变文档流（页头仍是 `sticky`），因此没有布局跳动。
- 锚点补偿使用实测高度：控制器把页头高度写入 `--header-h`，`scroll-padding-top` 取 `calc(var(--header-h) + 12px)`，向上跳转时目标不会被已经显现的页头压住。

## 响应式

- 页面容器 1120px（页头与首屏 1440px）；文章正文约 740px，桌面目录在侧边。
- 760px 以下目录成为正文前的折叠区域；600px 以下启用移动导航与竖向图文卡片。
- 桌面允许错位叠层，手机按阅读顺序纵向排列。
- 装饰层不遮挡内容，不产生横向溢出。

## 验收

检查 1440px 桌面、768px 平板、390px 手机和深色主题，覆盖首页、类型／标签、归档、搜索、五类详情与弹层，并检查中文、英文与减少动效模式。检查溢出、文字遮挡、图片加载、焦点、移动导航、长表格及代码横向滚动。自动截图位于 `test-results/`，验收证据归档在 `docs/evidence/`；只有实际打开并检查截图后才能记录视觉验收完成。

浏览器测试覆盖：背景层次与遮挡、文字区域平静、视差位移上限与归位、减少动效静态构图、深色逐层配置、模态层的焦点循环与背景 inert 与滚动恢复、浮层的外部点击与 Escape、移动目录折叠、快速重复开关、主题持久化与系统跟随、真实搜索、多语言、分页、草稿隔离与禁用 JavaScript 的回归。产物检查另外断言页面布局确实使用 Tailwind 工具类，且源码与产物都不残留 `select`、`details`、`dialog` 或系统提示调用。

软导航的检查项：点击站内链接不整页刷新（页面标记存活）、URL 与标题更新、后退同样走软导航；深色主题在软导航前后保持，`astro:after-swap` 时根属性已经是最终值（等价于「绘制前应用、不会闪」），新页面的控件选中态同步；重复来回导航后代码复制只增强一次、目录定位与浮层、模态层仍可用；搜索页第二次进入仍然返回结果；模态层打开时导航后 `inert`、滚动锁与模态层都不残留；`.xml` 链接带 `data-astro-reload`。

页头动效的检查项：三态切换、无布局跳动、键盘聚焦可达、减少动效瞬时切换、软导航后复位、锚点补偿；动效连续性通过**采样页头在视口中的位置**验证——隐藏与滑出都必须经过多个中间值而不是一次跳到位，滑出在贴顶时有轻微回弹再稳定，两个方向的过渡时长分别为 0.42s 与 0.26s；手动切换主题时断言出现临时过渡类并在约 340ms 后自动移除，减少动效下则不出现。六种状态各有一段录屏（贴顶、隐藏、滑出、手机贴顶、手机隐藏、深色滑出）保存在 `docs/evidence/header-scroll/`。
