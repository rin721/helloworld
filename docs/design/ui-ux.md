# UI/UX 规范

## 视觉基准

仓库根目录的 `ui.png` 是用户提供的设计基准。保留浅蓝灰、留白、几何光影、衬线标题与半透明面板。首页为真实 DOM 和 CSS 构图，示例插画为本地资产。

主要变量定义在 `src/styles/global.css` 的 `:root`：背景、表面、正文、次级文字、分隔线、强调色、浅色块和玻璃面板。浅色强调色为 `#476282`，深色为 `#b2c9e1`。排版使用本机可用的中文与英文衬线／无衬线字体，不依赖远程字体请求。

## 页面与模板

- 首页第一页：导航 → 介绍 → 精选 → 类型和标签 → 单列卡片 → 分页 → 页脚。其余分页直接进入列表。
- 文字卡片通过标题、摘要与留白组织层级；图文增加左侧封面；手机上图片移至文字上方。
- 图片分享允许没有摘要，预览使用完整图片比例，详情按顺序展示图片。
- 详情共用标题、日期、类型、标签和相邻文章导航；日记强调日期，学习笔记强化目录、代码与表格。
- 图片放大支持 Enter／空格打开、左右方向键切图、Escape 关闭并恢复焦点。
- 全站保留可直接访问的静态链接。浏览器脚本不负责生成文章主体。

## 响应式与交互

- 内容最大宽度 1120px；文章正文约 740px，桌面目录在侧边。
- 760px 以下目录成为正文前的折叠区域；600px 以下启用移动导航和竖向图文卡片。
- 明暗主题可跟随系统或手动选择；手动选择保存在浏览器中，系统变化仅在跟随系统时生效。
- 搜索支持输入、加载、结果、无结果、失败和重试；结果摘要高亮经过白名单处理。
- 列表切换语言时回到对应语言第一页；标签名称没有翻译映射时进入目标语言的标签索引，避免生成不存在的链接。
- 详情有译文时直接切换；无译文时弹出说明，读者可以关闭继续阅读或进入目标语言首页。

## 验收

检查 1440px 桌面、768px 平板、390px 手机和深色主题。检查溢出、文字遮挡、图片加载、焦点、移动导航、长表格及代码横向滚动。自动截图位于 `test-results/`；只有实际打开并检查截图后才能记录视觉验收完成。
