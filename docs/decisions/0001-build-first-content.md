# ADR-0001：构建优先的内容产品

- 状态：已接受；用户确认实施计划。
- 日期：2026-09-23。

## 背景

用户需要完整的现代博客体验，并明确将可提前计算的服务器工作移到构建阶段。技术栈已经定稿，不重新选型。内容既有文章、日记和学习笔记，也有文字、图文和图片展示形式。

## 决定

- 使用 Astro 静态输出与 Markdown Content Collections；构建阶段完成校验、摘要、聚合、分页、目录、译文关联、图片优化与搜索索引。
- 内容用途和展示形式分别建模，同一篇内容的语言文件由目录标识关联，译文可选。
- 浏览器承担搜索查询、主题、导航、目录跟随、图片查看和复制代码。
- 本期完整覆盖写作发布与阅读；读者写入能力不纳入。
- 采用真实的静态分页和筛选路由。中文、英文列表及搜索各自只包含已有译文内容。
- 使用 Cloudflare Pages Git 集成部署，GitHub Actions 执行工程验收。

## 后果

公开内容更新需要重新构建。私密草稿不应进入部署产物，必须在发布验证中检查。搜索需通过构建后的索引验收，不能用开发服务器的无索引状态推断产品能力。未来若新增读者数据写入需求，需要单独讨论，并保持既定技术基线约束。
