# 0005：双语路由与浏览器语言偏好

状态：已采用（2026-09-25）。

## 决策

页面语言仍由静态 URL 决定：中文在根路径，英文在 `/en/`。浏览器将读者选择保存为 `locale`；再次完整打开根首页时，英文偏好会在页面显示前跳到 `/en/`。直接访问文章等深链接时尊重 URL，并更新偏好；站内软导航也在页面更新后保存当前语言。存储不可用时，静态页面和切换链接仍可使用。

语言切换优先进入目标语言的同类静态页面。目标语言没有对应分页时进入其首页。文章只在存在译文时显示译文入口。单个静态 `404.html` 为两种语言同时提供错误说明。

## 原因与影响

静态构建不能按访问者偏好生成不同的根首页。将偏好跳转限制在根首页，可保留中文根路径和搜索引擎可访问的静态页面，同时让读者再次打开站点时回到所选语言。界面文案显式传入 `locale`，避免构建期间中英文页面共享可变语言状态。
